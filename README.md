## Beschrijving
wij hebben voor de opdracht een figma gekregen met een ontwerp wat we met html ,css en javascript na gaan bouwen de website is een website waarbij artsen hun ervaringen, evenementen en expertise/vaardigheden en ervaringen kunnen delen met mede artsen. Voor de eerste sprint was er gefocused op de dashboard volledig responsive en semantisch correct te creeëren en in de 2de sprint zijn we gefocust op toeganklijkheid van de gehele pagina.
